# Aether-Airship

Aether is an recon and delivery airship built to be remote controlled by a human. It can be accesed by connecting to it with wifi or the physical remote. Using buttons, it can land with a string which will have a magnetic part that is tied to it. The metal part, which could be as simple as a screw, will be stuck to the electromagnet we will have on the landing hub. Since it is an electromagnet, we will be able to turn it off, allowing Aether to leave the landing hub. Aether is powered using ESP-32's, and gets its lift from a large helium balloon, filled with about 75 liters of pure helium. It will have a small, lightweight camera on it, (Fun fact: its out of stock and has likely been discontinued, meaning we have a camera like no other) The gondola should weigh less than 75 grams to limit the size of the balloon, as one liter of helium can lift about 1 gram. We will have 2 brushed direct current motors to control the airship so it will be able to move. The controller will consist of a single joystick with a number of buttons to control the winch and electromagnets. The electromagnets will also have ESP-32's to control the electromagnet. Aether will use 3d printed parts for structure, and so we can customize it according to our needs. It will also use some balsa wood for weight reduction.
