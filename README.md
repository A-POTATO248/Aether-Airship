# Aether-Airship

Aether is built to be controlled by a remote by a human which can be accesed by connecting with wifi or the physical remote. Using buttons, it can land using a string with metal to connect to the electromagnet on the landing hub. Aether is powered
using ESP-32s. It gets its lift from a large ~5ft helium balloon filled with pure helium. The gondola should weight less than 75 grams to limit the size of the balloon. We will have 2 brushed dc motors to control the airship 
so it will be able to move. Controller will consist of a single joystick with a number of buttons to controll the winch and electromagnets. The electromagnets will also have esp32s to controll the electromagnet. Aether will use 3d printed parts
for structure. It will also use some balsa wood for weight reduction.
