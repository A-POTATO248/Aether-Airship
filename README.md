# Aether-Airship

Aether is an airship built to be remote controlled by a human. It can be accesed by connecting to it with wifi or the physical remote. Using buttons, it can land using a string with a magnetic part thats is tied to the it. The metal part, which could be as simple as a screw, will be stuck to the electromagnet we will have on the landing hub. Since it is an electromagnet, we will be able to turn it off, allowing Aether to leave the landing hub. Aether is powered using ESP-32's, and gets its lift from a large helium balloon, filled with about 75 liters of pure helium. The gondola should weight less than 75 grams to limit the size of the balloon, as one liter of helium can lift about 1 gram. We will have 2 brushed direct current motors to control the airship so it will be able to move. The controller will consist of a single joystick with a number of buttons to control the winch and electromagnets. The electromagnets will also have ESP-32's to control the electromagnet. Aether will use 3d printed parts for structure, and so we can customize it according to our needs. It will also use some balsa wood for weight reduction.
